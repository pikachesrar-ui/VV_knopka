# VV_knopka

AI-assisted short-form video studio for a small YouTube Shorts pilot.

## Pilot goal

Produce **15 review-ready Shorts** without automatic publishing:

- 8 AI-assisted animal/nature curiosity Shorts
- 7 cute/funny animal compilation Shorts
- 2 Russian experiments total (1 per pipeline)
- 13 English Shorts
- hard OpenAI pilot budget: **$10 USD**
- output is staged in `ready_for_review`; publishing is deliberately disabled for the pilot

## Editorial niche

**Animals / Nature Curiosities**

This keeps both formats coherent on one channel:

1. short original facts/stories about animal behavior and nature;
2. edited cute/funny animal compilations with meaningful editorial framing.

The project is designed to avoid mass-template spam and raw repost compilations. Source provenance, duplication checks, review gates, and AI-disclosure metadata are first-class parts of the pipeline.
